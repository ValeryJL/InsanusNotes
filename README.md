# InsanusNotes

Un entorno de trabajo interactivo (Workspace) que integra herramientas de productividad, notas enriquecidas y accesos directos a aplicaciones, impulsado por Electron.js.

## Características

- 📁 **Gestor de Cuadernos**: Organización visual de notas mediante cuadernos personalizados (nombre, color).
- 📝 **Editor de Notas**: Sistema completo de notas enriquecidas (Rich Text Editor).
- 🚀 **Dashboard de Apps**: Accesos directos a tus webs/apps preferidas con íconos dinámicos.
- 🎨 **Estética Personalizable**: Tema oscuro estilo Cyberpunk personalizable con colores dinámicos globales.
- ⚡ **Ligero y Rápido**: Construido íntegramente sobre Electron con Vanilla JS/CSS sin frameworks innecesarios.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone git@github.com:ValeryJL/InsanusNotes.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta la aplicación:
   ```bash
   npm start
   ```
